# Rutas Pasto — Documentación

Documentación técnica del proyecto **Rutas Pasto**: gestión de pedidos y
optimización de rutas de entrega en Pasto, desarrollado como proyecto de la
asignatura **Estructura de Datos**.

## Estructura

- `architecture/` — visión general, esquema 3D interactivo y producto
- `frontend/` — sistema de diseño, dirección visual e interfaz
- `backend/` — actualización empresarial del backend
- `deployment/` — despliegue en AWS e infraestructura CDK
